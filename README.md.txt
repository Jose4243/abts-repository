# Automated Book Tracking System (ABTS) - Semester 2

## Project Overview
This repository contains the web application (staff portal) and mobile application (member portal) for the Kensington Community Library Automated Book Tracking System.

## Repository Structure
- `web-app/`: Desktop web application interface for library staff (Dashboard, Loan Desk).
- `mobile-app/`: Mobile application interface for library members (Active Loans, Digital Member ID).
- `css/`: Stylesheets for desktop and mobile viewports.
